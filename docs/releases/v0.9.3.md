# Rain Alarm 0.9.3

Rain Alarm 0.9.3 keeps individual Lightning observations inside the exact selected Meteo regional
radar footprint.

## Fixed

- Individual Lightning points outside the active MeteoGroup regional coverage are no longer shown.
- The boundary remains enforced when the optional visual coverage shadow is reduced or disabled.
- OPERA and RainViewer behavior is unchanged.
- Lightning visuals and fading, notifications, widgets, providers and weather data are otherwise
  unchanged.

## Install or update

Download and open `RainAlarm-v0.9.3-release.apk`. Android may ask you to allow installation from the
app used to open the file.

This release supports Android 8.0+ and has version code **23**. It uses Rain Alarm's unchanged
permanent release certificate, so it can update an earlier official release-signed installation in
place while retaining places, widgets and settings. A debug-signed build cannot be updated in place
by this APK.

Individual-flash Radar remains experimental and depends on available satellite and regional radar
coverage. Weather observations can lag or be unavailable, and Rain Alarm is not a safety warning.

See the [user guide](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.3/docs/USER_GUIDE.md),
[data-source notes](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.3/docs/DATA_SOURCES.md)
and [privacy disclosure](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.3/docs/PRIVACY.md).
