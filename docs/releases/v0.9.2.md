# Rain Alarm 0.9.2

Rain Alarm 0.9.2 introduces individual Lightning observations directly alongside rain in Radar.

## Individual Lightning in Radar

- **EUMETSAT individual flashes (experimental)** is now the default Radar Lightning visual for new
  installs and upgrades without an existing Lightning-provider choice.
- Fresh satellite-observed flash centroids have a white centre and yellow glow. They continuously
  soften and deepen through amber, orange and red, then disappear at 20 minutes.
- Flash points remain at their observed coordinates while rain and forecast imagery follows its own
  Radar timeline.
- **EUMETSAT accumulated flash area** remains selectable in Settings. Any explicit valid provider
  choice is retained.
- App and widget Lightning notifications remain on the established accumulated flash-area detector;
  the new preference changes only the Radar visual.

The repository now includes a public
[clean-room self-hosting blueprint](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.2/docs/INDIVIDUAL_LIGHTNING_BACKEND.md)
for an equivalent EUMETSAT LFL relay and its exact mobile-feed contract. The backend implementation
and credentials are not published.

## Install or update

Download and open `RainAlarm-v0.9.2-release.apk`. Android may ask you to allow installation from the
app used to open the file.

This release supports Android 8.0+ and has version code **22**. It uses Rain Alarm's unchanged
permanent release certificate, so it can update an earlier official release-signed installation in
place while retaining places, widgets and explicit settings. A debug-signed build cannot be updated
in place by this APK.

Individual-flash coverage is limited to the app's supported UK, German, Dutch, Swiss and French
radar regions. EUMETSAT publishes completed upstream batches rather than a live strike stream, so
the view can lag observations or be unavailable. Centroids represent satellite-observed total
lightning; they are not guaranteed ground strikes, forecasts or safety warnings. Rain Alarm remains
an experimental information aid.
