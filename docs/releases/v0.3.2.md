# Rain Alarm 0.3.2

Rain Alarm 0.3.2 keeps the animated Radar experience continuous while Travel mode refreshes data in the background.

## What is included

- **Continuous Travel playback:** if the radar timeline is playing when Travel mode installs refreshed data for the same place and preferred provider, playback continues automatically. Manual Refresh uses the same handoff. Initial entry still starts paused, and deliberately scrubbing the timeline or opening a time from the Now chart still pauses it.
- **Reliable radar handoffs:** routine same-process renderer replacement is no longer mistaken for an interrupted display. Genuine renderer recovery remains available with concise user-facing wording and reduced texture residency where needed.
- **Preserved travel behaviour:** precise foreground location following, north-up centring, cadence-aware weather updates and screen-on behaviour are unchanged.

## Install or update

Download and open `RainAlarm-v0.3.2.apk`. Android may ask you to allow installation from the app used to open the file.

This release supports Android 8.0+ and has version code **16**. It is signed with Rain Alarm's unchanged permanent release certificate, so it can update an earlier official release-signed installation in place while retaining local data.
