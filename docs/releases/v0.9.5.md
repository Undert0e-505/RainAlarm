# Rain Alarm 0.9.5

Rain Alarm 0.9.5 adds a quiet stable-release indicator and makes the Radar Travel control an explicit toggle.

## New and changed

- Settings checks GitHub's public latest stable release only while Settings is active and the locally cached check is at least 12 hours old. A glowing indicator appears only for a newer version.
- Tapping the indicator opens that exact validated GitHub release page and dismisses the indicator for that version. Rain Alarm never downloads or installs an APK automatically.
- Tapping the highlighted Travel arrow now exits Travel while preserving the current map camera and displayed radar time. Tapping it again recentres on the current position and restores **AUTO**.
- Panning or zooming continues to exit Travel and preserve the resulting manual view.

## Install or update

Download and open `RainAlarm-v0.9.5-release.apk`. Android may ask you to allow installation from the app used to open the file.

This release supports Android 8.0+ and has version code **25**. It uses Rain Alarm's unchanged permanent release certificate, so it can update an earlier official release-signed installation in place while retaining places, widgets and settings. A debug-signed build cannot be updated in place by this APK.

The update check is an unauthenticated HTTPS request to GitHub when Settings is active and its 12-hour cache is stale. It sends no account, token or analytics data; GitHub receives normal network metadata. Weather observations can lag or be unavailable, and Rain Alarm remains an experimental information aid rather than a safety warning.
