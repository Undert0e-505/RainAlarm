# Rain Alarm 0.3.1

Rain Alarm 0.3.1 expands provider choice and makes radar coverage clearer without adding persistent clutter to the map.

## What is included

- **Provider-aware radar:** EUMETNET OPERA is now available as a credential-free European open-radar alternative alongside MeteoGroup regional feeds and RainViewer. Settings uses a pin for the global preferred provider; each selected place can use the best geographically eligible fallback without moving that pin.
- **Honest coverage display:** MeteoGroup's UK/Ireland feed uses a documented nominal radar-range envelope, OPERA shows current composite validity within its fixed pan-European grid, and RainViewer uses its published coverage mask. Unknown areas are darkened consistently; unavailable or malformed masks fail open rather than hiding the map.
- **Stable deep zoom:** complete regional OPERA and RainViewer imagery remains loaded and spatially aligned at every map zoom. Zooming in no longer replaces the regional map with only the selected-location analysis tile, and panning can reveal the rest of the cached region without another radar download.
- **Open-radar outlooks:** OPERA and RainViewer observations feed the app's confidence-gated motion estimate for Radar, Now and alerts. Fresh covered clear observations can report no rain; missing, stale, uncovered or unreliable evidence remains unknown rather than being presented as dry.
- **Better place search:** explicit named-place searches combine Open-Meteo settlements with Photon/OpenStreetMap POIs and, when those results are weak, a bounded Wikipedia/Wikimedia coordinate fallback. For example, `ragley estate's` resolves Ragley Hall rather than only an unrelated street result. Complete UK postcodes continue to use postcodes.io.

## Reliability and limits

- Provider loading has bounded, provider-aware timeouts and retains the preferred provider through session fallback.
- RainViewer regional imagery and coverage use the same planned bounds; OPERA reads only required COG metadata and byte ranges with bounded shared caching.
- Dynamic coverage scrims use one raster-compositing path inside and outside the loaded footprint to avoid rectangular shade seams at low zoom.
- Rapid preference, place, refresh and renderer changes remain generation-safe, and map-mask failure cannot darken the whole world.

Radar reach, freshness, forecast availability and intensity remain provider-dependent. MeteoGroup is not global, OPERA is limited to its pan-European product domain, and RainViewer's worldwide API still has published coverage gaps. OPERA and RainViewer future frames are Rain Alarm motion estimates, not provider forecasts. Rain Alarm is an experimental weather aid, not a safety-critical warning service.
