# Rain Alarm 0.3.0

Rain Alarm combines a selected-place next-hour outlook with a linked animated radar map and optional weather context. This release packages the current stable app experience for Android 8.0 and later.

## What is included

- **Now:** a north-up rain-arrival compass, source-aware status, local sunrise/sunset and selectable model temperature, pressure, humidity, UV and wind readouts. The linked minute timeline shows the provider's real available horizon and opens Radar at the chosen time. Rain and RainViewer's optional model-assisted **likely snow** use distinct textures, colours and wording.
- **Radar:** continuous observation-to-forecast scrubbing and playback, retained camera position and clean transitions between source frames. MeteoGroup/DTN regional radar is preferred where supported; RainViewer provides worldwide observations, an automatic session fallback and confidence-gated local motion estimates.
- **Independent map layers:** Wind, Lightning and Clouds can be enabled in any combination. Wind uses a bounded 25-point Open-Meteo model grid. EUMETSAT Lightning shows accumulated satellite flash areas, while Clouds switches between daytime Cloud Type and nighttime Fog / Low Clouds imagery. Satellite animations are prepared as complete place-bounded sets and cached for smooth reuse.
- **Travel mode:** virtual Current location uses foreground high-accuracy fused/GPS fixes. Follow keeps the marker centred, keeps the screen on only while visibly active, and checks radar, enabled overlays and point weather around their expected publication times. It does not request background location or run a foreground service.
- **Places and appearance:** search towns or complete UK postcodes, save the current fix, rename, reorder, pin and delete places, or long-press Radar to save a coordinate. Dark, Light, Follow-system and Slate choices are available where applicable for the app, map, compass and graph cards.
- **Alerts and privacy:** optional rain-approach notifications follow the active selected place and may notify again after the recorded rain window and grace period. The app has no account, ads, analytics or bundled provider credentials; live coordinates stay in memory unless explicitly saved.

## Reliability and performance

- Maps appear as soon as a coordinate is available while weather imagery continues loading in a compact status queue.
- Radar, Wind, Clouds, Lightning and Location expose consistent loading/unavailable states without replacing the normal screen. Manual Refresh starts a fresh generation for Radar and each enabled layer.
- Cloud and lightning frames use bounded regional requests, validated atomic disk caching and overlap during rendered handoff to reduce blank flashes.
- Wind acquisition retains usable arrows during replacement, tolerates slow connections, rejects obsolete viewport generations and now presents a newly fetched grid immediately after its positive map draw rather than waiting for a coarse freshness-clock tick.
- Rapid provider changes, refreshes, live fixes and place changes are generation-safe so older work cannot replace the latest selection.

## Install or update

Download and open `RainAlarm-v0.3.0-release.apk`. Android may ask you to allow installation from the app used to open the file.

This release supports Android 8.0+ and has version code **14**. It is signed with Rain Alarm's unchanged permanent release certificate, so it can update an earlier official release-signed Rain Alarm installation in place while retaining its local data. A debug-signed build uses a different certificate and cannot update an official release in place; uninstalling either build may remove locally stored places and settings.
