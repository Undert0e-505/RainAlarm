# Rain Alarm 0.2.0

This release makes the optional weather-map layers independent and restores Lightning and Fog on Android devices.

- Wind, Lightning and Fog now have three independent persistent controls. Any combination can be enabled, including all three, and existing single-layer settings migrate automatically.
- Wind arrows can coexist with both satellite layers. Fog renders below Lightning, each layer loads independently, and one failed EUMETSAT map tile no longer removes a metadata-verified layer.
- EUMETSAT capabilities parsing is compatible with Android's XML implementation while explicitly rejecting document types, entity declarations and external resolution.
- The Radar toolbar keeps Forecast/Observed with Follow, Refresh and recenter on the top row. A connected 144×48dp Wind/Lightning/Fog control occupies the second row with three 48dp touch targets and standard 24dp icons.
- Selected-place Wind remains visible while enabled. Lightning and Fog feedback remains through loading, holds its available or unavailable result for one second, then fades independently without disabling the layer. Fog remains selected while its daytime gate is active.
- Settings shows the Wind arrow-size preview whenever Wind is among the enabled layers.

## Install or upgrade

Install the signed `RainAlarm-v0.2.0-release.apk` on Android 8.0 or later. Version code 11 and the unchanged permanent release certificate allow an in-place update from signed v0.1.0–v0.1.9 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Optional layers depend on external provider coverage, freshness and connectivity. Wind is model-derived, Lightning shows satellite flash areas rather than verified ground strikes, and Fog shows nighttime fog/low-cloud imagery rather than confirmed surface fog. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for attribution, privacy and other limits.
