# Rain Alarm 0.1.2

This release improves saved places, live-location recovery, and the Now and Wind displays. It does not change rain providers or forecast algorithms.

- Rename saved places without changing their coordinates or alert/selection identity. Long-hold and drag saved rows into a persistent custom order; pinning a place promotes it once without re-sorting a later drag order.
- Radar's **Try again** requests a new foreground fix when virtual Current location is unresolved. The app checks permitted location providers concurrently and refreshes a stationary foreground fix without saving live coordinates or requesting background-location permission.
- Wind arrows stay distributed across the visible map at close zoom, even when a weather model reports multiple requested points in the same coarse cell. A Wind-only Settings slider adjusts arrow size from 0.5× to 2× with a live preview.
- Set the Now **Compass card** and **Graph card** independently to Follow app, Light, or Dark. Follow app remains the default; the surrounding app appearance is unchanged. Font-scaled Now readouts and the bottom direction label now reserve enough height to avoid clipping.

## Install or upgrade

Install the signed `RainAlarm-v0.1.2-release.apk` on Android 8.0 or later. Version code 3 and the unchanged release certificate permit an in-place update from signed v0.1.0 or v0.1.1 while preserving local places and settings. A debug-signed build uses a different certificate and cannot upgrade in place to this official release; uninstalling it may remove locally stored data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Rain and optional weather layers depend on provider coverage, freshness and network access; Wind values are model estimates, not site observations. Lightning depicts satellite flash **areas**, not individual ground strikes, and fog imagery is nighttime fog/low-cloud RGB, not confirmed surface fog. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for attribution, privacy and limitations.
