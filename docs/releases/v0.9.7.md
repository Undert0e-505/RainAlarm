# Rain Alarm 0.9.7

Rain Alarm 0.9.7 improves open-radar forecasting and fixes two refresh and navigation regressions.

- OPERA and RainViewer estimates now use a locally varying motion field, so separate rain systems can keep different directions instead of inheriting one dominant movement.
- Returning to a retained Radar view refreshes data after the provider has had an opportunity to publish a new frame, while a still-current view remains undisturbed.
- Tapping a time on the Now graph opens Radar for the same place at that exact time and keeps playback paused through loading or refresh.

MeteoGroup/DTN forecasts remain provider-supplied and unchanged.

This release is version 0.9.7 (version code 27) and supports Android 8.0 and later.
