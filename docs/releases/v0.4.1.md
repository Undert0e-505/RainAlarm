# Rain Alarm 0.4.1

Rain Alarm 0.4.1 makes the app easier to learn, faster to move around and more dependable while travelling, without changing its answer-first purpose.

## What is included

- **Guided first use:** a concise contextual tour highlights the real Now and Radar controls after first-launch language and permission choices. Its isolated Example forecast uses a deterministic, organic local radar field; it never writes weather caches or settings. The tour can be skipped and replayed from Settings.
- **Installed-app languages:** choose Device language, English, Dutch, Dutch (Belgium), German, French, Welsh or Irish on first use and later in Settings. Locale-aware strings, plurals, clocks and accessibility labels remain versioned in the app.
- **Clearer Places:** search, Choose on map and Current location share one focused flow. Saved rows expose direct startup-pin, edit and delete actions; Current can be saved explicitly. Now and Radar switch saved places in place, while **Selected now** stays independent from **Opens on startup**.
- **Appearance profiles:** optional automatic day/night profiles independently configure app, map, Compass and Graph appearances from cached sunrise/sunset facts. Manual Dark, Light, Slate and follow choices remain available, and place-focus transitions preserve the resolved palette.
- **Focused Now, Radar and Travel:** Now and Radar enter from a prepared first frame with a restrained focus transition; Radar settles the map, title and marker onto the exact retained view. Fifteen-minute labels align with their ticks, chart-selected times remain paused and retained sessions avoid unnecessary reloads. The always-visible Travel control requests precise fixes on a 200 ms raster, keeps the screen awake only while active and refreshes enabled data near provider publication.
- **Swipe navigation without losing map control:** the four phone destinations share one retained horizontal pager. Radar uses deliberate edge gutters so ordinary pan, zoom, rotation, controls and timeline gestures continue to win.
- **Interface refinements:** larger Compass status text, consistent switches and place controls, expandable data-source details, an always-visible version/source link and consistent appearance across Now and Radar.

## Install or update

Download and open `RainAlarm-v0.4.1-release.apk`. Android may ask you to allow installation from the app used to open the file.

This release supports Android 8.0+ and has version code **19**. It is signed with Rain Alarm's unchanged permanent release certificate, so it can update an earlier official release-signed installation in place while retaining local places and settings. Existing manual appearance, provider, notification and startup-place choices remain intact; automatic day/night stays opt-in.
