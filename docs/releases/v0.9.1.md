# Rain Alarm 0.9.1

Rain Alarm 0.9.1 refines Travel and makes rain notifications consistent across the app and every home-screen widget.

## Smoother Travel with responsive map control

- Live position and camera follow now move smoothly between trustworthy foreground location fixes while weather analysis remains anchored only to accepted device locations.
- A finger pan or pinch immediately suspends camera follow without stopping Travel's time automation or data updates. Travel or recenter resumes from the latest cached location.
- Map gestures, programmatic camera movement and provider/style refreshes are separated so ordinary updates do not unexpectedly take camera control.

## Exact AUTO timeline hand-off

- Travel's inline **AUTO** marker follows the exact current forecast time without shifting the underlying timeline or colliding with ordinary labels.
- Pressing Play hands off from the precise AUTO instant; scrubbing takes manual time control without disabling location Travel.
- Tapping the Now graph opens Radar at the selected time and retains that choice through loading and provider promotion until compatible coverage is ready.

## Unified app and widget notifications

- Every widget now has independent **Widget notifications** and **Include lightning** controls, with notifications on and Lightning off by default.
- App and widget deliveries share rain/Lightning episode identity at the same place, preventing duplicate cross-source alerts while keeping sibling widgets independent.
- Rain and likely-snow titles now include the event's expected **Light**, **Medium** or **Severe** intensity from the same normalized next-hour graph used by Now.
- Rain-now, approaching rain, combined rain/Lightning and Lightning-only alerts retain truthful timing, event boundaries, quiet hours and localized wording.

## Install or update

Download and open `RainAlarm-v0.9.1-release.apk`. Android may ask you to allow installation from the app used to open the file.

This release supports Android 8.0+ and has version code **21**. It uses Rain Alarm's unchanged permanent release certificate, so it can update an earlier official release-signed installation in place while retaining local places, widgets and settings. A debug-signed build cannot be updated in place by this APK.

Rain Alarm remains an experimental information aid. Radar, widgets and notifications depend on third-party coverage, freshness, network access, device location delivery and Android scheduling. See the [user guide](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.1/docs/USER_GUIDE.md), [notification requirements](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.1/docs/NOTIFICATION_REQUIREMENTS.md), [data-source notes](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.1/docs/DATA_SOURCES.md) and [privacy disclosure](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.1/docs/PRIVACY.md).
