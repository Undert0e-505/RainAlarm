# Rain Alarm 0.9.4

Rain Alarm 0.9.4 makes individual Lightning available from the first represented feed instant, so
the full Radar observation slider can show the valid history that exists.

## Fixed

- The oldest Radar frames no longer show an erroneous **Lightning unavailable** gap.
- Those frames may contain a partial trail rather than the full 20 minutes because Rain Alarm only
  renders represented observations.
- No points are synthesized, future flashes remain hidden, and the existing 20-minute fade,
  expiry and Meteo regional clipping are unchanged.
- The backend/feed contract, notifications, widgets, providers and weather data are unchanged.

## Install or update

Download and open `RainAlarm-v0.9.4-release.apk`. Android may ask you to allow installation from the
app used to open the file.

This release supports Android 8.0+ and has version code **24**. It uses Rain Alarm's unchanged
permanent release certificate, so it can update an earlier official release-signed installation in
place while retaining places, widgets and settings. A debug-signed build cannot be updated in place
by this APK.

Individual-flash Radar remains experimental and depends on available satellite and regional radar
coverage. Weather observations can lag or be unavailable, and Rain Alarm is not a safety warning.

See the [user guide](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.4/docs/USER_GUIDE.md),
[data-source notes](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.4/docs/DATA_SOURCES.md)
and [privacy disclosure](https://github.com/Undert0e-505/RainAlarm/blob/v0.9.4/docs/PRIVACY.md).
