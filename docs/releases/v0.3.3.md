# Rain Alarm 0.3.3

Rain Alarm 0.3.3 makes radar coverage clearer and consistent across every configured region while leaving the underlying rain imagery unchanged.

## What is included

- **Consistent Meteo coverage:** all five MeteoGroup regions now distinguish nominally covered areas from unknown space. The existing UK/Ireland envelope is unchanged; Netherlands/Benelux, Germany, France and Switzerland gain evidence-backed nominal radar-network envelopes clipped to each feed's native footprint.
- **Adjustable coverage darkness:** one persistent **Coverage mask darkness** control applies to MeteoGroup, OPERA and RainViewer. Choose **No mask** for a fully transparent scrim or increase it in 10% steps; the live split preview shows the effect before returning to Radar.
- **Theme-aware range:** the 50% default gives effective opacity of 45% on Dark, 42% on Slate and 40% on Light. Maximum strength reaches 90%, 84% and 80% respectively while retaining some map context.
- **No weather reset:** changing mask darkness updates only the map scrim. It does not reload radar or ancillary weather, move the camera or reset the timeline.

## Coverage note

The continental Meteo envelopes describe nominal structural radar-network reach, not a live or contractual DTN validity boundary. DTN does not publish site membership or a validity mask for these legacy composites, so Rain Alarm uses documented national-network evidence cross-checked with the current EUMETNET OPERA radar database. Terrain, beam blockage, outages, quality loss near range limits and changing composite inputs are not represented. A missing or unsafe mask fails open rather than hiding the map.
