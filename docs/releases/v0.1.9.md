# Rain Alarm 0.1.9

This release adds a mid-dark Slate appearance across Radar and the two Now cards while making labels easier to read on darker maps.

- Appearance settings now use one aligned four-column layout. App keeps Dark, Light and Follow system; Map adds persistent Slate; Compass and Graph independently add Slate beside Dark, Light and Follow app.
- Map Slate uses OpenFreeMap Fiord and keeps the current radar session, selected timeline position, camera, marker and weather overlays when changing styles.
- Compass and Graph Slate each use the same `#45516E` base with a dark high-contrast palette. Ready, loading and unavailable cards respect their independent selections without changing rain/snow textures, intensity bands, typography or animation.
- Dark and Slate maps use separate high-contrast place, road, road-reference and water label colours with dark halos. Existing font sizes, positions, filters, icons and hierarchy remain style-owned; Light map labels are unchanged.

## Install or upgrade

Install the signed `RainAlarm-v0.1.9-release.apk` on Android 8.0 or later. Version code 10 and the unchanged permanent release certificate allow an in-place update from signed v0.1.0–v0.1.8 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Radar resolution, coverage and freshness vary by provider, and normalized severity is not rainfall or snowfall rate. Notification checks are scheduled by Android and may be delayed by Doze, connectivity or provider availability. Current location uses foreground fixes only.
