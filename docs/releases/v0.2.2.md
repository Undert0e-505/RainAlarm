# Rain Alarm 0.2.2

This release makes the optional satellite overlays usable as complete, place-bounded animations rather than isolated map snapshots.

- One persistent **Clouds** control now selects EUMETSAT MTG Cloud Type RGB in daylight and Fog / Low Clouds RGB at night, with a deterministic solar fallback and automatic product changes across the radar timeline.
- Clouds and Lightning follow the observed radar cursor at their advertised 10-minute and 5-minute cadences. The latest real satellite observation is held through radar forecast time; no satellite forecast is invented.
- Each enabled satellite overlay prepares its complete finite observation-window frame set for the selected place's bounded operating region before reveal. The fixed regional image survives pan/zoom, prevents world-scale requests and deliberately overscales when viewed closely.
- Verified regional PNGs now use an atomic app-managed 128 MiB cache and local bitmap-backed MapLibre sources. This replaces unreliable remote-source readiness that could leave Clouds stuck at `Preparing 0/N`, while cache reuse avoids repeat downloads on animation loops.
- Frame handoff keeps the outgoing image visible until the incoming bitmap has been composited in a later fully rendered map frame, avoiding blank flashes. Clouds and Lightning prepare, render and fail independently.
- Radar Refresh forces fresh EUMETSAT catalogue and current-frame checks for both cloud products without purging valid immutable frame files. Rapid refresh generations are superseded safely, and status distinguishes verified-file preparation, rendering, readiness and failure.

## Install or upgrade

Install the signed `RainAlarm-v0.2.2-release.apk` on Android 8.0 or later. Version code 13 and the unchanged permanent release certificate allow an in-place update from signed v0.1.0–v0.2.1 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. EUMETSAT imagery is observed satellite data, not a cloud forecast, ground-strike feed or proof of surface fog. The selected place determines a fixed regional request with approximately 200 km of surrounding margin; close zoom overscales a maximum-1024px source. Enabled satellite layers send bounded WMS requests to EUMETSAT and keep validated compressed frames in an app cache; disabled Clouds makes no cloud request. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for attribution, privacy and other limits.
