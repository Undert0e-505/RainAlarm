# Rain Alarm 0.1.5

This update polishes Radar refresh and live-location labelling. Radar data sources, forecast calculations, alerts, and map controls are unchanged.

- Refresh progress and failure feedback now appear as a small bottom-right map overlay, above any optional layer status. The existing map, title, and timeline keep their positions during a same-place refresh; the Refresh button stays in its original place.
- When a refreshed radar session creates a new map, a dark- or light-matched cover remains until the requested MapLibre style has rendered its first frame. This prevents the default white frame from flashing in Dark mode. If the style fails or stalls, the matched cover displays a retry message instead of a blank white map.
- If platform reverse geocoding cannot provide a locality name for Current location, its label is one-decimal latitude and longitude without a prefix. A resolved locality, county, or region remains preferred.

## Install or upgrade

Install the signed `RainAlarm-v0.1.5-release.apk` on Android 8.0 or later. Version code 6 and the unchanged release certificate allow an in-place update from signed v0.1.0–v0.1.4 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Radar and forecast coverage depend on external providers and connectivity; zooming cannot add real detail to source imagery. The map-style cover does not repair a failed network connection, and a style-load failure still needs a retry. Current location uses foreground fixes only. Wind is model-derived, Lightning shows satellite flash **areas** rather than individual ground strikes, and Fog shows nighttime fog/low-cloud imagery rather than confirmed surface fog. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for data sources, attribution, privacy and other limits.
