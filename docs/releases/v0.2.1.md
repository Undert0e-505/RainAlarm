# Rain Alarm 0.2.1

This patch improves map readability while loading, place handling, and the spacing of the Wind overlay.

- Visible Wind arrows now form a regular 3×3 grid at the quarter, centre and three-quarter positions of the settled viewport, while the existing offscreen sample rows and columns retain coverage during map movement.
- Complete UK postcodes, with or without their space, use an exact postcodes.io lookup. Results keep the canonical postcode and available administrative locality detail; ordinary town searches continue to use Open-Meteo.
- A resolved live Current location can now be explicitly saved as an ordinary place, after which it supports rename, reorder, pin, delete, startup selection and normal saved-place alerts.
- Radar's first load uses a bounded Dark, Light or Slate map-card shell with compact bottom-right progress and stable timeline space instead of a large central spinner or an apparently blank pane.
- Rapid radar-provider changes now keep the last selected option, settle for 400 ms, and start only the final expensive Now analysis instead of repeatedly allocating sessions for intermediate taps.

## Install or upgrade

Install the signed `RainAlarm-v0.2.1-release.apk` on Android 8.0 or later. Version code 12 and the unchanged permanent release certificate allow an in-place update from signed v0.1.0–v0.2.0 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Radar, search and model layers depend on external provider coverage, freshness and connectivity. Complete UK postcode searches are sent to postcodes.io; other place-search text is sent to Open-Meteo.
