# Rain Alarm 0.9.6

Rain Alarm 0.9.6 keeps retained map weather data current after returning to the app, fits Places search text within the field at enlarged Android font scales, and suppresses main-app weather notifications during Travel while leaving widgets independent.

## New and changed

- Returning to Radar after the active provider's next publication opportunity automatically refreshes the retained radar session and enabled map overlays while keeping existing imagery and the camera visible during replacement.
- The Places search query now fits the field's actual editable vertical viewport under enlarged and nonlinear Android font scaling, retaining normal Material typography whenever it fits.
- Travel silently consumes main-app rain, Lightning and combined notification candidates without writing a delivered claim. This prevents catch-up app alerts for the same episode after Travel ends, while widgets remain independently eligible to notify.

## Install or update

Download and open `RainAlarm-v0.9.6-release.apk`. Android may ask you to allow installation from the app used to open the file.

This release supports Android 8.0+ and has version code **26**. It uses Rain Alarm's unchanged permanent release certificate, so it can update an earlier official release-signed installation in place while retaining places, widgets and settings. A debug-signed build cannot be updated in place by this APK.

Weather observations, provider publication times and background scheduling can lag or be unavailable. Rain Alarm remains an experimental information aid rather than a safety warning; do not rely on it as your only source for weather-safety decisions.
