# Rain Alarm 0.1.8

This release simplifies the Radar map's information layout and makes its live-location controls clearer, especially on narrower phones.

- The map now keeps only MapLibre's compact native attribution control. Radar and weather provider details have moved to Settings under **About the data**, including Open-Meteo and EUMETSAT CC BY 4.0 attribution.
- Wind speed/direction and concise Wind, Lightning or Fog availability now sit directly beneath the current-location control. Provider names and freshness ages no longer crowd the map; the existing internal freshness checks still withhold stale data.
- For Current location, Follow now shares the top control row immediately before Layers. Its icon follows the map's light/dark control colour while off, uses the app accent while active, and no longer has a background.
- The Forecast/Observed frame label stays anchored on the top row and safely ellipsizes on narrow maps instead of colliding with the controls. Radar refresh feedback remains an unobtrusive bottom-right overlay.

## Install or upgrade

Install the signed `RainAlarm-v0.1.8-release.apk` on Android 8.0 or later. Version code 9 and the unchanged permanent release certificate allow an in-place update from signed v0.1.0–v0.1.7 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Radar resolution, coverage and freshness vary by provider, and normalized severity is not rainfall or snowfall rate. Provider/source times continue to drive the app's stale-data safeguards even though ancillary-layer ages are no longer displayed over the map. Notification checks are scheduled by Android and may be delayed by Doze, connectivity or provider availability. Current location uses foreground fixes only. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for attribution, privacy and other limits.
