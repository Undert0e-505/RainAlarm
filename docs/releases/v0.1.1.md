# Rain Alarm 0.1.1

This patch fixes a release-only failure that could make MeteoGroup regional radar switch immediately to RainViewer after its first image, leaving the regional Now outlook unavailable. Android's release optimizer removed constructors needed by the regional map-projection library. The release build now retains those constructors for every configured regional projection. No weather source, forecast algorithm, or user-facing feature has changed.

## Install or upgrade

Install the signed `RainAlarm-v0.1.1-release.apk` on Android 8.0 or later. Version code 2 and the unchanged release signing certificate allow an in-place update from the public v0.1.0 release, preserving local places and settings. A debug-signed APK uses a different certificate and cannot be upgraded in place to this release-signed APK; uninstalling it can remove locally stored data.

This is an experimental weather aid, not a safety-critical warning service. Radar and Now still depend on provider availability, coverage, freshness, network access and the limitations described in the [README](https://github.com/Undert0e-505/RainAlarm#readme). The [v0.1.0 release notes](https://github.com/Undert0e-505/RainAlarm/releases/tag/v0.1.0) remain available for the original feature set and attribution.
