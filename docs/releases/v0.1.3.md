# Rain Alarm 0.1.3

This release refines Now and Radar navigation and fixes saved-place deletion. It does not change radar providers or forecast algorithms.

- The Now intensity chart uses its full coloured plot width, with the Now axis at the left edge and the last available forecast minute at the right. Ten-minute local-clock tick marks stay aligned with that domain; the Now label is centred on its axis and nearby clock labels appear when they fit. Tapping the plot opens Radar at the corresponding continuous forecast time.
- Now and Radar use aligned selected-place headers and a shared outlined place-switch icon. Radar also has a selected-place centring button beside its title; it retains zoom and does not request a different device location. The Now compass cardinal labels are larger.
- Deleting any saved place, including the selected, pinned, default or final saved row, removes it persistently. After the final deletion the app selects virtual Current location rather than silently recreating London; a fresh foreground fix is still required before location-based forecasts are available.
- Phone-installable previews use the established release signing key so they can update a release installation in place. This does not change the published app's signing identity.

## Install or upgrade

Install the signed `RainAlarm-v0.1.3-release.apk` on Android 8.0 or later. Version code 4 and the unchanged release certificate permit an in-place update from signed v0.1.0–v0.1.2 while preserving local settings. A debug-signed build has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Coverage, freshness and forecast horizon depend on external providers and connectivity; source imagery cannot gain real detail when zoomed. Wind is model-derived, Lightning shows satellite flash **areas** rather than individual ground strikes, and Fog shows nighttime fog/low-cloud imagery rather than confirmed surface fog. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for sources, attribution, privacy and other limits.
