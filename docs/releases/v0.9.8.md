# Rain Alarm 0.9.8

Rain Alarm 0.9.8 fixes Radar time selection from the Now graph.

- Tapping a time on the Now graph now moves Radar to that time after leaving Travel mode.
- The selected time also applies correctly when Radar safely reuses compatible data after switching between saved and current places.
- Radar stays paused at the selected time until you press Play, scrub the timeline, or explicitly re-enter Travel.

This release is version 0.9.8 (version code 28) and supports Android 8.0 and later.
