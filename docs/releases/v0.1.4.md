# Rain Alarm 0.1.4

This update refines saved-place feedback and the Now compass, and adds optional live-map following. Radar providers, forecast sources, and rain/alert decisions are unchanged.

- Deleting a saved place removes its row immediately, including the last or selected place. If the local store rejects the change, the row returns with an error message.
- The compass's E label sits closer to the ring. When rain is predicted, the centre disc and direction pointer share a colour based on the highest available forecast-envelope intensity, with Light, Medium and Severe mapped consistently across providers. A missing direction still hides the pointer; a dry forecast keeps the plain blue disc.
- With virtual Current location selected, fresh foreground fixes move the map marker without moving a manually positioned map. A Current-only Follow control below map recenter centres the latest fix immediately and continues centring each new fix at the existing zoom. A map gesture turns Follow off; an unavailable fix stops it. Current recenter no longer clears a still-fresh map while obtaining another fix.

## Install or upgrade

Install the signed `RainAlarm-v0.1.4-release.apk` on Android 8.0 or later. Version code 5 and the unchanged release certificate allow an in-place update from signed v0.1.0–v0.1.3 while preserving local settings. A debug-signed APK has a different certificate and cannot update an official release in place; uninstalling it may remove local data.

Rain Alarm is an experimental weather aid, not a safety-critical warning service. Radar and forecast coverage depend on external providers and connectivity; zooming cannot add real detail to source imagery. Live following uses foreground device fixes only, not background tracking, and its accuracy depends on device location. Wind is model-derived, Lightning shows satellite flash **areas** rather than individual ground strikes, and Fog shows nighttime fog/low-cloud imagery rather than confirmed surface fog. See the [README](https://github.com/Undert0e-505/RainAlarm#readme) for data sources, attribution, privacy and other limits.
