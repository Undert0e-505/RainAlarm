# Rain Alarm 0.9.9

Rain Alarm 0.9.9 makes Radar location and provider changes reliably install the correct dataset and visible coverage area.

- Selected locations are accepted only when the installed radar data actually covers them.
- If the preferred radar source does not cover a selected location, Radar uses a covered fallback or clearly reports that radar is unavailable.
- Switching between saved, current and Travel locations now replaces incompatible radar data while safely reusing data that still covers the selected location.

This release is version 0.9.9 (version code 29) and supports Android 8.0 and later.
